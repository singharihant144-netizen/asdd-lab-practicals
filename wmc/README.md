# WMC Study Pack

Three original Python simulations supplied for the Wireless and Mobile Communications lab:

- `experiments/handover_simulation.py` — signal strengths and a handover point for two base stations.
- `experiments/multipath_effect.py` — delayed and attenuated paths and their received waveform.
- `experiments/wmcexp2.py` — BPSK bits, additive white Gaussian noise, detection, and BER.

Install Python 3, NumPy, and Matplotlib (`python -m pip install numpy matplotlib`) before running. Each script opens Matplotlib plots. The scripts are preserved as supplied; no separate database was included.
