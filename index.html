Tell the story in order

  1. AimWhat were you trying to learn?

[ READY-TO-GO CHECKLIST ]

Before you walk in

  • I can state the objective and main tool for every experiment.
  • I can explain Jira, the backlog, and a Sprint.
  • I can explain Git staging, commits, branches, and merging.
  • I can name the CI trigger and success check.
  • I can describe the Dockerfile, image, container, and output.
  • I can explain Nginx, Redis, port 8080:80, and localhost:8080.
  • I can explain Kubernetes Pods, Deployments, and replicas.
  • I know the actual project and resource names from my own setup.

Be accurate about what you ran. If a command didn’t run on your machine, explain its purpose without claiming it succeeded.
