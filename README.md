# aa hacks

A responsive study site for seven ASDD practicals and a viva preparation bank with 124 questions and answers from six experiments. It includes a guide-based troubleshooting helper named aa and download buttons for the original DOCX and viva PDF.

## Publish with GitHub Pages

This folder is ready to publish as a static GitHub Pages site from the root of the `main` branch. No build step or secrets are required.

## Files

- `index.html` — aa hacks page and the ASDD Lab / Viva Prep tabs
- `style.css` and `style-viva.css` — responsive design, motion, and study layouts
- `app.js` and `viva-data.js` — practical details, all viva questions, search, and guide-based troubleshooting
- `asdd-hack-aa2.docx` — original practicals guide download
- `asdd-viva-questions.pdf` — original viva questions download

The aa helper runs entirely in the browser. It searches the practicals and documented fixes; it is not connected to a hosted generative AI service.
