# ASDD Lab

A responsive, static learning site for seven ASDD practicals. It includes a document-grounded troubleshooting helper named aa and a download of the original practicals DOCX.

## Publish with GitHub Pages

This folder is ready to publish as a static GitHub Pages site from the root of the `main` branch. No build step or secrets are required.

## Files

- `index.html` — page structure and content sections
- `style.css` — responsive design and motion
- `app.js` — practical details, interactions, and local troubleshooting responses
- `asdd-hack-aa2.docx` — original downloadable experiment guide

The aa helper runs entirely in the browser. It searches the practicals and documented fixes; it is not connected to a hosted generative AI service.
